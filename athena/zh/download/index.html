你需要

安装前请确认以下几项。

  • macOSmacOS 13 Ventura 或更高版本
  • AI 智能体Claude Code 或 Codex，用你自己的账号登录。
  • git 和 Python 3如果没有，首次启动时 macOS 会提示安装。想提前安装，可在终端运行 xcode-select --install
  • Node.jsAthena 应用使用 Node 24.22.1。
  • GitHub需要能访问你的仓库。创建拉取请求和自动审查需要 gh CLI。

已经安装？文档中的入门会带你完成第一个包和第一个请求。

安装 Athena Studio 即表示你同意最终用户许可协议。
