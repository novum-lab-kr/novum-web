Athena Studio 有哪些新变化

按从新到旧列出 Athena Studio 每个公开版本的变化。

0.47v0.47.0 – v0.47.52
2026 年 11 月 1–3 日

更新应用或核心时不再关闭 pane。

v0.47.51

  • 改进Athena pane 无法立即接收消息时（例如正在显示提问界面），代理发送的消息不会变成提问请求，而是等待，待可以接收后按顺序送达。

v0.47.46

  • 改进Claude 回答完毕后，即使后台 shell 仍在运行，工作区也会将 pane 显示为空闲。pane 标题栏会显示 pane 编号和后台 shell 数量（>_）。

v0.47.45

  • 新功能恢复连同工作记录一起导出的包时，现在也会重新打开 Codex 对话（前提是这台电脑上有该 Codex 记录）。
  • 改进看板的“学习”标签页现在同时显示 Claude 和 Codex 的个人记忆。

v0.47.44

  • 新功能在 Athena 文件夹中启动的 Codex 按与 Claude 相同的规则担任团队负责人。

v0.47.43

  • 修复以 Codex 运行的审查者 pane 在审查结束后也会自动关闭。

v0.47.42

  • 新功能无法使用 Claude 时，拉取请求自动审查和学习审查会使用 Codex。

v0.47.41

  • 修复更新弹窗不再显示早期版本的内容。

v0.47.40

  • 修复代理监视器的旧行不再留下 [?] 标签。

v0.47.39

  • 修复Codex 代理 pane 在信任其钩子后不再损坏。

v0.47.38

  • 改进在提问、权限确认、信任或模型选择界面等待的 pane，现在会在工作区、代理监视器、看板和菜单栏中显示为等待输入，等待期间 Athena 不会复用或关闭它们。

v0.47.37

  • 新功能Codex pane 中的提问和权限确认现在也会像 Claude 一样显示在“工作”里，问题的回答会送回该 pane。

v0.47.36

  • 修复发送到 pane 的文本不再停留在输入框中未发送：Athena 会确认已送达，必要时再次按 Enter。

v0.47.35

  • 新功能代理和审查者可以作为 Codex pane 在仓库工作区中运行。

v0.47.32

  • 新功能Claude 和 Codex 均已登录时，Athena 会询问使用哪个工具启动，并记住选择。在 Athena 工作区启动另一个工具会更新此选择。

v0.47.31

  • 改进Codex 会话现在也使用与 Claude 会话相同的提交、机密值和进程保护钩子。
  • 改进代理监视器现在会同时显示 Claude 和 Codex 会话，包括模型、工具活动和摘要。

v0.47.30

  • 改进自动审查达到轮次上限后，最后的修复仍会先对改动代码进行简短审查，再合并。有阻碍合并的问题或审查失败时，会停止合并。

v0.47.28

  • 修复向空闲的代理 pane 续发新工作时，会在该 pane 实际工作的文件夹中创建新分支；如果该文件夹是仓库的原始文件夹（主检出），则拒绝。
  • 修复由其他 pane 在对话中代为回答的问题，答案会送达提问的 pane。

v0.47.27

  • 新功能拖动 pane 的标题栏放到同一标签页中的另一个 pane 上，即可移到那里：会放在离指针最近的上、下、左、右一侧，并预先显示放置位置。pane 中运行的程序不会中断，按 Esc 可取消。

v0.47.26

  • 新功能可以按仓库把完整验证和合并交给 GitHub Actions，代理无需等待即可接下一项工作。默认关闭，适用于关闭自动 PR 且无需确认直接合并的仓库。看板卡片会显示 Actions 状态，失败时会通知原来负责的代理 pane。

v0.47.25

  • 修复菜单栏面板中的代理列表不再出现横向滚动条，滚动条样式也与深色面板一致。

v0.47.24

  • 新功能看板新增浅色/深色模式切换按钮。所选模式会被记住，选择之前跟随系统设置。

v0.47.23

  • 改进看板的指标标签页以中位数（同时显示平均值和 p75）显示从开始到首次合并的时间，并与上一周期比较。新增了“等待回答”阶段，并可按开始日期和是否经过审查筛选。

v0.47.22

  • 改进代理在工作过程中只检查修改的部分，完整验证只在任务结束时运行一次。

v0.47.21

  • 修复看板现在从 Claude Code 实际使用的文件夹读取 Athena 的 Claude 记忆，记忆列表不再显示为空。

v0.47.20

  • 修复多个决策控制台不再互相覆盖而消失：每个控制台在侧边浏览器中以单独的标签页打开，新的控制台排在当前页面后面的标签页中，提交后只关闭该标签页并切换到下一个控制台。

v0.47.15

  • 修复切换 pane 时,右侧边栏不再闪现加载状态或错误的标题:新内容准备好之前会保留之前的内容。

v0.47.14

  • 改进智能体监视器的每一行现在会显示回答的模型,时间精确到秒。

v0.47.13

  • 修复当焦点在 Athena 窗口时,即使其他应用占用了 ⌘⇧J 和 ⌘⇧K,也能移动 pane 焦点。

v0.47.12

  • 新功能pane 中的权限确认现在也会显示在“工作”里,并可直接跳转到该 pane。允许或拒绝仍在 pane 中操作,操作后“工作”中的该项会关闭。
  • 改进即使正在查看 Athena pane,其中的问题现在也会显示在“工作”里,你可以在任一处回答。

v0.47.8

  • 改进pane 焦点切换快捷键从 ⌘⌥ + 方向键改为 ⌘⇧I J K L(上、左、下、右)。

v0.47.7

  • 修复关闭自动 PR 时，Athena 会阻止误开拉取请求，并提示改用直接合并。

v0.47.6

  • 修复当智能体在 Athena pane 中请你选择选项而你没有在看它时，问题会转到待办，你可以在那里回答。

v0.47.1

  • 新功能通过包的 permissionsAllow 为该仓库的代理 pane 允许特定命令后，这些命令无需权限确认即可运行。
  • 修复代理的完成通知现在会等到其后台命令结束后才发送。
  • 修复代理 pane 现在可以把审查修改推送到打开的拉取请求，即使该拉取请求没有等待中的请求。
  • 修复没有决策控制台的决策请求现在仍保持为决策，并以问题弹窗打开，可直接在应用中回答。

v0.47.0

  • 新功能更新应用或核心时不再关闭 pane：正在运行的 pane 会切换到新代码并继续运行。
  • 新功能如果 pane 运行的是无法切换的旧版本，Athena 会列出将被关闭的 pane，只有在你选择时才关闭。否则可以继续照常使用。

0.46v0.42.3 – v0.46.4
2026 年 11 月 1 日

代理会读取仓库规则，小型拉取请求走快速通道。

v0.46.1

  • 修复等待自动合并期间，如果拉取请求的基准分支发生变化，将不再合并。

v0.46.0

  • 新功能Athena 会查找每个仓库的规则文档，并将全文载入代理会话。可以在包中添加或排除文档。

v0.44.0

  • 新功能小型拉取请求走 ⚡ 快速通道：由一位审查者审查一次，经过一轮修复后，只要验证和冲突检查通过即可合并。可按仓库关闭。

v0.43.0

  • 改进指标标签页现在显示各阶段用时（工作、验证、审查、等待合并）、审查轮数和每次合并的修复数。

0.42v0.40.4 – v0.42.2
2026 年 10 月 31 日

更新后窗口先打开，核心更新在后台完成。

v0.42.1

  • 安全补丁已将 Electron 升级到 44.10.0，应用内置的 Node 现为安全版本 24.22.1。

v0.41.1

  • 修复拆分或关闭 pane 时，不再凭粗略估计去改动相邻 pane 的终端大小。

v0.41.0

  • 改进重启后窗口先打开，核心更新在后台进行：标签栏显示“核心更新中”，完成后弹出结果窗口。包命令、新的代理 pane 和补进度会等更新结束后再进行。

v0.40.9

  • 改进核心更新弹窗会显示简短的类型标签，只有最后一位版本号变化的更新也会列出最近的变更。

0.40v0.32.5 – v0.40.3
2026 年 10 月 30 日

按仓库选择 Athena 是否打开 PR。

v0.40.0

  • 新功能关闭某个仓库的自动 PR 后，会跳过 PR 和审查，验证通过的工作分支直接合并到基础分支。

v0.36.1

  • 改进耗资源命令的第二个名额现在还要等 CPU 负载低于核心数时才开放。

v0.36.0

  • 新功能在设置中可以按仓库选择 Athena 是否打开 PR、是否运行自动审查、是否合并。合并可以自动进行、先在工作界面询问，或由你自己来。

v0.35.2

  • 修复代理的提问不再从工作弹窗中消失。未回答的提问会保留，直到代理确认或取消；读取请求失败时会显示错误，而不是空列表。

v0.35.0

  • 改进构建、测试等耗资源的命令最多可同时运行两个。第二个名额只在内存充足时才开放。

v0.33.0

  • 新功能委派的代理完成一轮后，Athena 会自动收到通知。代理的“下一条提示”建议已关闭，不会再把残留的建议误认为你正在输入的文字。

0.32v0.28.8 – v0.32.4
2026 年 10 月 30 日

每次更新后，可在应用内直接查看变化。

v0.32.0

  • 新功能Athena 核心更新后，应用内弹窗会显示旧版本和新版本、更新内容以及更新结果。

v0.31.3

  • 改进设置中 PR 自动化开关下方的警告行已移除。

v0.31.2

  • 改进设置中的 PR 自动化开关改为按开启的功能命名：“自动 PR · 审查”和“批准后立即合并”。

v0.31.1

  • 改进核心更新弹窗中，正在工作的会话以代理名称显示。

v0.31.0

  • 改进代理 pane 启动时不加载 MCP 服务器，每次回复使用的 token 更少。审查者 pane 保持不变。

v0.30.0

  • 新功能在没有 Athena Studio 仓库的包中报告 Athena 自身的 bug 时，会生成隐藏了个人信息的 GitHub issue 草稿。Athena 先展示草稿并在 GitHub 上打开，由你确认后自行提交。

v0.29.0

  • 改进同一仓库的代理 pane 空闲时，Athena 会把新任务继续发到那个 pane，而不是再打开新的 pane。

v0.28.9

  • 修复修复了提交信息有多行，或路径使用 ~ 或变量时，提交保护钩子错误拦截 Athena 自身提交脚本的问题。

v0.28.8

  • 修复在开启自动合并的仓库中，代理不再请你合并它打开的 PR。自动审查会一路推进到合并，代理会报告 PR 状态。
