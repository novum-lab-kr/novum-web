Athena Studio 是一款运行 AI 编程智能体的 Mac 应用。把要做的事告诉团队负责人 Athena，它会写好计划，给每个仓库分配一个智能体，遇到需要决定的事再来问你。你只需看 diff、合并。

下载 macOS 版 查看使用流程 ↓

免费 · macOS 13 及以上 · Apple Silicon / Intel · 需要 Claude Code 或 Codex

安装 → 连接仓库 → 向 Athena 提需求 → 回答问题 → 检查 PR

为什么选择 Athena Studio

同时处理多个仓库

一个需求可以同时涉及 web、api 和 mobile。Athena 会拆分任务，每个仓库的智能体在各自的分支上同时工作。

只在需要决定时介入

智能体的问题集中在一个 [工作] 列表里，不必翻遍终端去找谁在等你。

合并前先检查

智能体在打开拉取请求前会运行测试。在开启自动审查的仓库中，合并前会根据审查意见修正。

逐渐熟悉每个仓库

任务结束后保留的笔记，会被该仓库的下一项任务读取。

01

Athena 把一个需求按仓库拆开。

Athena 制定计划并把工作交给负责的智能体。每个智能体在自己的分支上实现，需要决定时会留下问题。

在演示项目中实际发出的需求顾客总是放弃购物车。在 web 上加一个已保存购物车的提醒，再把 api 的订单历史做成分页，让 mobile 也能用。

02 · api · 订单历史

智能体有问题时，会出现在 [工作] 里。

订单历史每页显示 20 条还是 50 条？问题会出现在“工作”里，菜单栏会出现红点。发送答案后，智能体就会继续。

演示中选择了 20 条。界面为英文演示。

03 · web · 购物车提醒

代码改动与测试结果并排查看。

在终端旁阅读 diff，确认验证结果后再合并。PR 自动审查与合并按仓库设置，也可以保留合并前确认。

演示中 web 仓库的购物车任务：6 项测试通过以及 CartPage.tsx 的改动。

04

与你已在用的编程智能体配合使用。

Athena Studio 直接运行你已在用的 Claude Code 或 Codex，并在其上加入团队负责人、书面计划和审查。

代码会去哪里
应用不会把你的代码或文件发送到 Novum Lab 的服务器。AI 请求发往你使用的服务商，推送发往你的 GitHub。详情
费用
Athena Studio 本身免费。AI 用量按你的 Claude 或 Codex 套餐计费。
语言
英语、韩语、日语或中文，同时用于应用和智能体。待办页面(⌘2)目前只有韩语。
所需条件
macOS 13 或更高版本。PR 自动审查需要 Claude Code。完整条件
