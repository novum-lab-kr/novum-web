功能

Athena Studio 功能一览

应用各部分的作用。分步骤的用法请看文档。

工作区

每个仓库都有自己的工作区。

左侧列出你的仓库，以及在其中工作的分支和智能体。中间是标签页和拆分终端，每个智能体都有自己命名的 pane。右侧是 Explorer。

  • 每个任务一个标签页，标签页内可拆分 pane
  • 智能体 pane 以智能体和分支命名，Athena 的 pane 以它正在规划的任务命名
  • 关闭窗口，一切照常运行；重新打开还是同样的标签页和布局
  • 同一仓库里有空闲的智能体 pane 时，新任务直接交给它而不再新开；没有时，把最大的 pane 沿长边拆分来安放
  • 把 Finder 中的文件或文件夹拖到 pane 上，路径会粘贴到其输入行；按下 Enter 前不会发送任何内容
  • 拖动边缘可调整工作区列表、Explorer 和监视器的大小
  • 为仓库设置显示名称和图片，通过包与团队共享
进度与问题

看到每个智能体在做什么，以及需要你做什么。

智能体监视器

窗口底部的实时动态逐个工具地跟踪每个智能体：读过和改过的文件、运行的命令，以及过程中说的话。在每个工作区都能看到。

工作

智能体需要你时，问题或决定会出现在 [工作] 最上方，下面是进行中的任务和最近一天完成的任务。在那里回答后，智能体会从停下的地方继续。

还可以监视仓库中未关闭的 GitHub 议题：开启后，新议题会作为任务导入并交给 Athena，智能体监视器会为每个议题显示一行。

pane 详情

从智能体的标题栏打开详情，一个面板会从窗口上方滑出，不会改变终端的大小。它显示智能体需要你做什么、被什么卡住、它的计划和拉取请求。

菜单栏

Mac 菜单栏里有 Athena Studio 的猫头鹰图标。出现红点表示有待回答的问题或受阻的计划。点击猫头鹰即可看到每个智能体的状态。

决策与代码

做出决定，再看代码。

需要做多个决定时，整理成决策控制台。

当一份计划有多个需要决定的事项时，Athena 会把它们整理成决策控制台：每个选项都附有利弊和推荐。它在智能体旁边的侧边浏览器中打开，你做出选择后，智能体就会继续。

  • 必选和可选的决定，标出推荐选项
  • 侧边浏览器（⌘⇧B）用于计划、决策控制台和本地测试页面
  • 独立的登录信息，沙盒运行，只支持 http 和 https

在终端旁边阅读工作成果。

浏览当前工作区的文件和 git 改动，并在终端旁边打开。改动过的文件以 diff 形式打开。

  • 带 git 状态（M · U · A · D · R）的文件树和改动列表
  • 语法高亮、行号和图片
  • 只读取工作区文件夹内的内容；按 Esc 关闭查看器
审查与学习

拉取请求经过审查，经验得以保留。

PR 自动审查与修复

在开启自动审查的仓库里，智能体一推送就会审查只涉及该仓库的 PR。意见返回给智能体，最多修改 3 轮后进入合并环节。大的 diff 优先审查代码，之前的批准会保留。

  • 默认关闭，在设置中按仓库选择自动 PR、自动审查和合并方式
  • 合并可选自动、确认后(在 [工作] 中询问你)或手动(由你来合并)
  • 为每个角色选择模型，从智能体到审查者
  • 审查结果和合并都会记录在计划和拉取请求上
  • 关闭自动 PR 后，不建拉取请求也不审查，工作分支会直接合并到基准分支，并遵循你的合并设置

只把你选中的笔记带到下一项任务。

合并后，学习审查会根据过程中出现的内容(从审查意见到 QA 结果)提出笔记建议。只有你在 [学习] 中选中的才会保存为该仓库的学习笔记，智能体在下一项任务开始时读取。

学习 · api

+ 列表接口使用基于 createdAt 的游标分页，每页 20 条。
+ 响应结构：{ items, nextCursor }。mobile 读取同样的结构。

包与语言

每家公司一个包，用你工作的语言。

每家公司一个包。

一个包包含一家公司的仓库、智能体和路由规则。每个包独立运行，切换时不会中断另一个包里的工作。

  • 用 Mac 上的仓库创建包，或从文件、文件夹或 git 仓库导入
  • 一键切换；另一个包里的智能体会在原处继续工作
  • 连同你的工作一起导出，包括智能体对话和未完成的分支，之后再恢复

选择应用和智能体的语言。

在“显示”菜单中选择英语、韩语、日语或中文。应用随之切换，智能体也一样：回复、计划、问题、学习笔记和提交信息都会跟着变。

在 Mac 上试试 Athena Studio。

适用于 macOS 13 及以上的 Apple Silicon 和 Intel Mac，免费使用。
