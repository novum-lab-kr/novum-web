Athena Studio の機能紹介

アプリの各部分の役割です。手順ごとの使い方はドキュメントにあります。

ワークスペース 進捗と質問 決定とコード レビューと学習 パックと言語
ワークスペース

リポジトリごとに専用のワークスペース。

左にはリポジトリと、そこで作業しているブランチとエージェント。中央はタブと分割ターミナルで、エージェントごとに名前のついた pane があります。右には Explorer。

  • 作業ごとのタブ。タブの中は pane に分割できます
  • エージェントの pane にはエージェント名とブランチ、Athena の pane には計画中のタスク名
  • ウィンドウを閉じてもすべて動き続け、開き直せば同じタブとレイアウト
  • 同じリポジトリで待機中のエージェント pane があれば新しい pane を開かずそこへ引き継ぎ、なければいちばん大きい pane を長い辺の方向に分けて配置します
  • Finder からファイルやフォルダを pane にドラッグすると、パスが入力行に貼り付きます。Enter を押すまで何も送られません
  • 端をドラッグして、ワークスペース一覧・Explorer・モニターの大きさを変えられます
  • リポジトリに表示名と画像をつけ、パックでチームと共有
進捗と質問

エージェントが何をしていて、あなたに何を求めているかが分かります。

エージェントモニター

ウィンドウ下部のライブフィードが、各エージェントをツールごとに追いかけます。読んだファイル、編集したファイル、実行したコマンド、途中の発言まで。どのワークスペースでも表示されます。

作業

エージェントがあなたを必要とすると、その質問や決定が [作業] の一番上に出ます。その下に進行中の作業と、この 1 日で終わった作業が並びます。そこで答えると、エージェントは止まったところから続けます。

リポジトリの未解決の GitHub イシューを見張ることもできます。オンにすると、新しいイシューが作業として取り込まれて Athena に渡され、エージェントモニターにイシューごとに 1 行表示されます。

pane の詳細

エージェントのタイトルバーから詳細を開くと、ターミナルのサイズはそのままにウィンドウの上へパネルが出てきます。エージェントがあなたに求めていること、止まっている理由、計画書、プルリクエストを表示します。

メニューバー

Mac のメニューバーに Athena Studio のフクロウがいます。赤い点は、未回答の質問か止まっている計画があるという意味です。フクロウをクリックすると、エージェントごとの状態が見られます。

決定とコード

決めることを決めて、コードを読む。

決めることが多い計画は、決定コンソールにまとめます。

計画に決めることが複数あると、Athena はそれを決定コンソールにまとめます。選択肢ごとにトレードオフと推奨をつけて。エージェントの隣のサイドブラウザで開き、あなたが選べばエージェントは作業を続けます。

  • 必須と任意の決定、推奨の選択肢を表示
  • サイドブラウザ(⌘⇧B)で計画書、決定コンソール、ローカルのテスト画面
  • サインインは別保存、サンドボックス、http と https のみ

作業を、ターミナルの隣で読む。

現在のワークスペースのファイルと git の変更を見て、ターミナルの隣に開きます。変更されたファイルは diff で開きます。

  • git の状態(M · U · A · D · R)つきのファイルツリーと変更一覧
  • シンタックスハイライト、行番号、画像
  • 読むのはワークスペースのフォルダ内だけ。Esc でビューアーを閉じる
レビューと学習

プルリクエストはレビューを経て、学んだことは残ります。

PR の自動レビューと修正

自動レビューをオンにしたリポジトリでは、エージェントがプッシュすると、そのリポジトリだけの PR がすぐレビューされます。指摘はエージェントに戻り、最大 3 ラウンド修正したあとマージの段階に進みます。大きな diff はコードから先に見て、それまでの承認は引き継がれます。

  • 初期設定はオフ。設定でリポジトリごとに自動 PR・自動レビュー・マージ方法を選びます
  • マージは 自動・確認後([作業] で確認)・手動(自分でマージ)から選べます
  • 役割ごとにモデルを選択。エージェントからレビュアーまで
  • レビュー結果とマージは計画書とプルリクエストに記録
  • 自動 PR をオフにすると、プルリクエストとレビューを省き、作業ブランチを基準ブランチへ直接マージします。マージ設定はそのまま従います

選んだノートだけを次の作業へ。

マージ後、学習レビューがレビューの指摘から QA の結果まで、作業中に出た内容をもとにノートを提案します。[学習] であなたが選んだものだけがそのリポジトリの学習ノートに残り、エージェントは次の作業の最初にそれを読みます。

パックと言語

会社ごとにパックを。作業する言語で。

会社ごとにパックを用意します。

パックには、ひとつの会社のリポジトリ、エージェント、ルーティングのルールが入っています。パックごとに独立して動くので、切り替えても別のパックの作業は止まりません。

  • Mac 上のリポジトリからパックを作成、またはファイル・フォルダ・git リポジトリから取り込み
  • ワンクリックで切り替え。別のパックのエージェントはその場で作業を続けます
  • エージェントの会話や未完了のブランチも含めて書き出し、あとで復元

アプリとエージェントの言語を選べます。

表示メニューで英語・韓国語・日本語・中国語を選べます。アプリが切り替わり、エージェントもついてきます。返答、計画書、課題、学習ノート、コミットメッセージまで。

Mac で Athena Studio を使ってみましょう。

macOS 13 以降の Apple Silicon・Intel Mac で無料で使えます。
