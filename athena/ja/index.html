AIエージェントを統率し、

Athena Studio は AI コーディングエージェントを動かす Mac アプリです。チームリードの Athena にやりたいことを伝えると、計画を立ててリポジトリごとにエージェントを割り当て、決めることがあればあなたに聞きます。あなたは diff を見てマージします。

Coming soon 使い方の流れ ↓

無料 · macOS 13 以降 · Apple Silicon / Intel · Claude Code または Codex が必要

インストール → リポジトリをつなぐ → Athena に依頼 → 質問に答える → PR を確認

Athena Studio を選ぶ理由

複数のリポジトリを同時に

ひとつの依頼が web・api・mobile にまたがっても大丈夫です。Athena が分け、リポジトリごとのエージェントがそれぞれのブランチで同時に作業します。

あなたは決めるときだけ

エージェントの質問はひとつの [作業] リストに集まります。誰があなたを待っているか、ターミナルを探し回る必要はありません。

マージ前に確認

エージェントはプルリクエストを開く前にテストを実行します。自動レビューを有効にしたリポジトリでは、マージ前に指摘を受けて直します。

リポジトリを覚えていく

作業後に残したノートを、そのリポジトリの次の作業が読みます。

01

ひとつの依頼を、Athena がリポジトリごとに分けます。

Athena が計画を立て、担当のエージェントに作業を渡します。エージェントはそれぞれのブランチで実装し、判断が必要なら質問を残します。

デモプロジェクトで実際に送った依頼カートの放棄が多い。web に保存済みカートのリマインダーを追加して、mobile でも使えるように api の注文履歴をページ分割して。

02 · api · 注文履歴

エージェントに質問があれば、[作業] に届きます。

注文履歴を 1 ページに 20 件表示するか、50 件にするか。質問は「作業」に届き、メニューバーに赤い点がつきます。答えを送ればエージェントが続けます。

デモでは 20 件を選びました。画面は英語のデモです。

03 · web · カートのリマインダー

変更したコードとテスト結果を並べて見る。

ターミナルの隣で diff を読み、検証結果を確認してからマージします。PR の自動レビューとマージはリポジトリごとに設定でき、マージ前の確認を残すこともできます。

デモの web リポジトリのカート作業: テスト 6 件通過と CartPage.tsx の変更内容。

04

いつも使っているコーディングエージェントと一緒に使えます。

Athena Studio は、いつも使っている Claude Code や Codex をそのまま動かし、その上にチームリード・計画書・レビューを加えます。

コードの行き先
アプリがコードやファイルを Novum Lab のサーバーに送ることはありません。AI へのリクエストはお使いの提供元へ、プッシュはあなたの GitHub へ送られます。詳しく
料金
Athena Studio 自体は無料です。AI の利用料はお使いの Claude または Codex のプランで請求されます。
言語
英語・韓国語・日本語・中国語。アプリとエージェントの両方に適用されます。作業リスト(⌘2)は今のところ韓国語のみです。
必要なもの
macOS 13 以降。PR 自動レビューには Claude Code が必要です。すべての条件

インストールと初回設定はドキュメントへ →
