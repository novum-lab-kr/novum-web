macOS 版 Athena Studio

バージョン 0.42.0 · 2026 年 10 月 31 日 · 変更点

macOS 13 Ventura 以降で無料で使えます。Apple の署名・公証済みです。

2020 年以降のほとんどの Mac Apple Silicon M1 · M2 · M3 · M4 以降 .dmg をダウンロード v0.42.0
以前の Mac Intel Intel プロセッサの Mac .dmg をダウンロード v0.42.0

どちらかわからない場合は → この Mac について で「チップ: Apple M…」なら Apple Silicon、「プロセッサ: Intel」なら Intel です。

必要なもの

インストール前に確認してください。

  • macOSmacOS 13 Ventura 以降
  • AI エージェントClaude Code または Codex に、ご自身のアカウントでサインインしてください。
  • git と Python 3ない場合は、最初の起動時に macOS がインストールを案内します。事前に入れるにはターミナルで xcode-select --install
  • Node.jsAthena のスクリプトが使います。セキュリティパッチ入りのバージョンを使ってください：22.x は 22.23.4 以上、24.x は 24.22.1 以上、26.x は 26.12.1 以上。アプリ内の Node は別のもので、パッチ済みの 24.22.1 です。
  • GitHubリポジトリへのアクセス。プルリクエストと自動レビューには gh CLI が必要です。

インストールしましたか? ドキュメントのはじめかたで、最初のパックと最初の依頼まで案内します。

Athena Studio をインストールすると、エンドユーザー使用許諾契約に同意したものとみなされます。
