Before you install

Check these first.

Athena Studio runs on your Mac and drives the coding agent you already use.

  • macOSmacOS 13 Ventura or later
  • AI agentClaude Code or Codex, signed in with your own account. Both is even better: Codex joins pull request reviews.
  • git and Python 3Part of Apple's Command Line Tools. If they're missing, macOS offers to install them on first launch.
  • Node.jsUsed by Athena's scripts
  • GitHubAccess to your repositories. The gh CLI is needed for pull requests and automatic review.

Install and open

Install Athena Studio.

  1. Download the .dmg for your Mac's chip from the Download page.
  2. Open the downloaded file and drag Athena Studio into Applications.
  3. Open Athena Studio. It's signed and notarized by Apple, so it opens without a security warning. If git or Python 3 is missing, macOS offers to install Apple's Command Line Tools.
  4. On first launch the start screen offers New Pack and Import Pack. A pack is the set of repositories, agents and rules for one company or project.

First setup

First setup: Athena learns your repositories

When you create a pack, Athena sets it up for you. It only reads your code.

You confirmWhich repositories to include, the company name, agent names and where automatic review is on. Fix any wrong guesses here.
Athena preparesAn agent for each repository with its rules and notes, the routing table, QA checks and a code baseline. Your repositories aren't changed, and it asks before installing or fetching anything.
When it's doneAthena reports what it made and what still needs you. Then ask for your first task in the athena workspace.
What Athena does, step by step
  1. Finds the repositories on your Mac and guesses each one's type (front end or back end), production branch and PR base.
  2. Asks you to confirm which repositories to include, the company name, agent names and where automatic review is on. Wrong guesses get fixed here.
  3. Creates an agent for each repository with its rules, structure notes, a gotchas notebook and a check script.
  4. Reads each repository's production branch and fills in what the agent handles, the rules it must follow, language and type status, and a short service overview. Athena also writes the routing table, which says which request goes to which repository.
  5. Drafts QA checks for each app's screens.
  6. Runs the checks once and takes a code baseline, so later updates only touch what changed.
  7. If you want, draws diagrams for each service: structure, screen map and request flow.

Have a pack from your team? Use File → Import Pack… and pick an archive, a pack folder or a git repository.

Your first task

From one request to a merged pull request.

The demo project below is a small shop with web, api and mobile repositories. Your own repositories work the same way.

01

Ask Athena

In the athena workspace, type what you want changed and which repositories it touches. Plain words are fine.

Customers keep abandoning carts. Add a saved-cart reminder on web, and paginate order history in api so mobile can use it too.
02

Check the plan

Athena writes a plan for each repository and hands it to that repository's agent, which works on its own branch in a new pane. When a plan has several choices, Athena opens a decision console in the side browser so you can pick.

03

Answer questions

When an agent needs a decision, Work at the top right shows a dot and the question waits under Waiting for you. Click it, pick an answer, add a note if you like, and send. The owl in the menu bar gets a red dot too.

04

Follow the work

The agent monitor at the bottom of the window shows what each agent is reading, editing and running. For one agent's plan, blockers and pull request, open details from its pane's title bar.

05

Check the change

Agents run tests and checks before they open a draft pull request. In Explorer on the right, open Changes and click a file to read its diff next to the terminal.

06

Merge

In repositories with PR auto-merge on, the pull request is reviewed and fixed automatically. If Confirm before merging is on, the merge waits for your click. In other repositories, merge on GitHub as usual.

07

Keep what was learned

After the merge, the learning review suggests notes. Open the work board (⌘2), go to Learning and pick the ones to keep. The next task in that repository reads them. The work board is in Korean for now.

Around the app

Where things are.

Workspaces
The left list has one workspace per repository, with its branches and agents. The middle holds tabs and split panes, one agent per pane. ⌘1 brings you back here.
Agent monitor
Bottom of the window. Shows only agents that are working right now; fold it away with ⌄.
Work
Top right of the tab bar. Questions waiting for you, work in progress and what finished in the last 24 hours.
Work board (⌘2)
Opens in your default browser: issues, QA, learning, metrics and archive. In Korean for now.
Pane details
The icon at the right of an agent pane's title bar. Plan, progress, blockers, tokens and the pull request; Esc closes it.
Explorer
Right side. Files and Changes for the current workspace; changed files open as a diff.
Side browser
A drawer on the right (⌘⇧B) for plans, decision consoles and local test pages. Its sign-ins are kept apart from your main browser.
Menu bar
The owl in the Mac menu bar. A red dot means a question is open or a plan is blocked; click for every agent and its status.

Settings

Change how Athena Studio works.

PR auto-merge
⚙ at the right end of the tab bar. One switch per repository, with Confirm before merging under it. Off until you turn it on.
Language
View → Language. The app and your agents switch together: replies, plans, issues and commit messages.
Notifications
Click the owl in the menu bar → Pause Notifications, for an hour or until 9 the next morning.
Packs
The pack name at the left of the tab bar (⌘⇧P). Switch, create, import or export. Agents in the other pack keep working, and an export can include agent conversations and unfinished branches.
Repository name and image
Right-click a repository in the left list. The name and image are saved in the pack, so your team sees them too.

Updating

Keep Athena Studio up to date.

From 0.17.6 on, the app updates itself: open Settings (⚙) and, when a new version is out, press Update on the App update line. The app downloads it, verifies it, and restarts. If anything fails, the current version keeps running and a short reason is shown.

Still on 0.15.8? That version can't update itself. Download the new .dmg once from the Download page and drag Athena Studio into Applications to replace the old app. Your packs and work stay where they are, and after that you can update from ⚙.

The Athena core that comes with the app is updated when you open a new version, even while agents are working.

Data and security

What runs on your Mac, and what is sent elsewhere.

The app runs on your computer. Your agents still send requests to their AI provider, and your code goes to GitHub when they push.

Runs on your MacAgents, terminals and the worklist run locally. The app does not send your code or files to Novum Lab's servers.
Your own AI accountAgents run as the Claude Code or Codex you already signed into, under that provider's terms and your plan.
Agents work on branchesEach agent works on its own branch and worktree. Automatic merge is off until you turn it on for a repository.
Signed and notarizedPublic release builds are signed with an Apple Developer ID and notarized by Apple.
A separate browserThe side browser is sandboxed, opens only http and https, and keeps its sign-ins apart from your main browser.
TypeSafe Jev is optionalOnly if you add your own TypeSafe Jev key, QA error details and learning notes are sent to TypeSafe Jev. Without a key, nothing is sent to it.

Troubleshooting

If something goes wrong.

Panes look disconnected or stop responding
View → Reattach Terminal. Panes and agents stay as they are.
Reattaching doesn't help
View → Restart Terminal Daemon. This closes all open panes, including their agents.
An agent seems stuck
Look in Work for a question waiting for you, and in the pane's details for a blocker.
No pull request opens
Make sure the gh CLI is installed and signed in (gh auth login), and that the repository has a GitHub remote.
Claude Code, Codex, git or Python is missing
Install it and sign in from Terminal (for git and Python: xcode-select --install), then reopen Athena Studio.
Nothing else works
View → Reset Studio deletes every pack and pane and restarts the app. Your repository folders are kept. Use it last, after reporting an issue.

Logs are in ~/Library/Application Support/Athena Studio (daemon.log, board.log, pack.log). Attach them when you report an issue.

FAQ

Questions

Which Macs does it run on?

macOS 13 Ventura or later, on Apple Silicon or Intel. It's free to download.

How much does it cost?

Athena Studio is free to download and use. Your agents run on your own Claude Code or Codex plan, so their usage is billed by that provider as usual.

Do I need Claude Code or Codex?

Yes, at least one of them, signed in on your Mac. Agents can run on either. Automatic PR review uses Claude Code; with Codex as well, it adds a second reviewer from a different model.

Will agents merge code on their own?

Only if you turn it on. Automatic merge is off by default and set per repository, and you can keep a final click before every merge.

Do agents keep working when I close the app?

Yes. Terminals and agents keep running in the background, even after you quit. Open the app again and you're back to the same tabs and layout.

Can I use it for more than one company or project?

Yes. Make a pack for each: its repositories, agents and rules. Switching packs doesn't stop work in the other one, and you can export a pack for your team.

What about Windows or Linux?

Athena Studio is a Mac app for now.

Found a bug or have an idea?

Open an issue on GitHub and pick a bug report or a feature request.
