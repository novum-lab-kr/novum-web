Get started

Data and security

Your code stays on your Mac.

Athena Studio runs on your computer with tools you already trust. Here's exactly what goes where.

Runs on your MacAgents, terminals and the worklist run locally. The app does not send your code or files to novum's servers.
Your own AI accountAgents run as the Claude Code or Codex you already signed into, under that provider's terms and your plan.
Branches, not your mainEach agent works on its own branch and worktree. Automatic merge is off until you turn it on for a repository.
Signed and notarizedRelease builds are signed with an Apple Developer ID and notarized by Apple, so macOS opens them without a warning.
A separate browserThe side browser is sandboxed, opens only http and https, and keeps its sign-ins apart from your main browser.
Optional means optionalExtras that send data elsewhere only switch on when you add your own key. Without one, nothing is sent.

FAQ

Questions

Can I use Athena Studio now?

Not yet. The first public build for macOS is almost ready. Get notified and we'll email you when it's out.

How much does it cost?

Athena Studio is free to download and use. Your agents run on your own Claude Code or Codex plan, so their usage is billed by that provider as usual.

Do I need Claude Code or Codex?

Yes, at least one of them, signed in on your Mac. With Claude Code alone you get the full team. Add Codex and pull request reviews get a second opinion from a different model.

Do I need to install Athena separately?

No. The app brings the Athena core with it and sets it up on first launch.

Does my code leave my Mac?

Not to us. Athena Studio does not send your code or files to novum's servers. Your agents talk to their own provider (Anthropic or OpenAI) as they normally do, and pushes go to your GitHub.

Will agents merge code on their own?

Only if you turn it on. Automatic merge is off by default and set per repository, and you can keep a final click before every merge.

Do agents keep working when I close the app?

Yes. Terminals and agents keep running in the background. Even after you quit, open the app again and you're back to the same tabs and layout.

Can I use it for more than one company or project?

Yes. Make a pack for each: its repositories, agents and rules. Switching packs doesn't stop work in the other one, and you can export a pack for your team.

What about Windows or Linux?

Athena Studio is a Mac app for now.
