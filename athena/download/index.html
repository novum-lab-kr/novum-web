What you need

Check these before you install.

  • macOSmacOS 13 Ventura or later
  • AI agentClaude Code or Codex, signed in with your own account.
  • git and Python 3If they're missing, macOS offers to install them on first launch. To install ahead of time, run xcode-select --install in Terminal.
  • Node.jsThe Athena app uses Node 24.22.1.
  • GitHubAccess to your repositories. The gh CLI is needed for pull requests and automatic review.
