What you need

Check these before you install.

  • macOSmacOS 13 Ventura or later
  • AI agentClaude Code or Codex, signed in with your own account. Both is even better: Codex joins pull request reviews.
  • git and Python 3Part of Apple's Command Line Tools. If they're missing, macOS offers to install them on first launch.
  • Node.jsUsed by Athena's scripts
  • GitHubAccess to your repositories. The gh CLI is needed for pull requests and automatic review.
