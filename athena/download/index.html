What you need

  • A Mac running macOS
  • Claude Code or Codex, signed in with your own account
  • git, and GitHub access to your repositories
Get started

Three steps to your first agent.

  1. Install. Open the downloaded file and drag Athena Studio into Applications.
  2. Open it. On first launch the app sets up the Athena core for you. There's nothing else to install.
  3. Add your repositories. Create a pack or import one from your team, then start your first agent.
