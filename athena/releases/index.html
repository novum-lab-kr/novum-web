Release notes

What's new in Athena Studio

What changed in each public build of Athena Studio, newest first.

0.52v0.52.0 – v0.52.1
Nov 6, 2026

v0.52.1

  • NewBefore an agent starts, Athena checks the plan's instructions and warns about missing or unclear parts, and the Board's Metrics tab summarizes these checks by kind.
  • ImprovedThe Board now follows the app's language (English, Korean, Japanese or Chinese).
  • ImprovedThe Board's issue list is grouped by repository, and an issue's delete button appears only when you hover over or focus its row.
  • ImprovedThe Diagram menu includes Athena's work-flow diagrams again, updated to the current flow.
  • ImprovedPack import errors explain what you chose, what is missing and what to do next, and the pack error dialog no longer hides the details in a collapsed section.
  • FixedThe green eyes of the menu bar owl icon were barely visible while agents were working.
  • FixedAfter creating a new pack, the sign-in tool now starts automatically in the Athena pane.
  • FixedThe first-run repository search no longer opens macOS protected folders (Music, Movies, Pictures, Library) that trigger access prompts.

See everything in v0.52.1 on GitHub

0.51v0.50.4 – v0.51.38
Nov 3–5, 2026

v0.51.38

  • FixedThe wide-change check no longer counts HTML screen code as documentation.

v0.51.37

  • ImprovedThe instruction-check group in the Metrics tab is aligned to the grid and now has color.

v0.51.35

  • ImprovedThe instruction section of plan templates is tidied into fixed short fields, and a check script now warns (without blocking) when a plan's instruction section does not follow them.
  • ImprovedThe Metrics tab now shows the instruction-check numbers: plans checked, plans with warnings, stop notices and the warning kinds.

v0.51.34

  • ImprovedThe "details" fold in the pack error window is gone.

v0.51.33

  • ImprovedPack import error messages now say what you picked, what is missing and what to do, in plain words.

v0.51.32

  • FixedFirst-run repository search no longer opens the Mac-protected Music, Movies, Photos and Library folders, so the access permission dialog no longer appears.

v0.51.31

  • FixedAfter creating a new pack, claude / codex now start automatically in the Athena pane.

v0.51.30

  • FixedThe layout of the auto-merge button in app settings no longer breaks when you hover over it.

v0.51.29

  • ImprovedThe Worklist, decision consoles and Athena's messages (session start notices, permission requests in Work and choice questions) now follow the app's language: English, Korean, Japanese or Chinese.
  • ImprovedThe guide menu, its Getting started and structure explanation screens, and the /guide skill have been removed. Open diagrams from the app's Diagram button.

v0.51.28

  • ImprovedThe diagram list shows Athena's own workflow diagrams again, redrawn for the current workflow: one for the lightweight and formal paths and one for auto save around compact, in the app's language.

v0.51.27

  • ImprovedIn the Worklist's Metrics tab, the detailed numbers now sit above the full task list in an aligned grid, and the full task list is split into pages of 100.

v0.51.26

  • ImprovedThe Worklist's issue list groups issues by repository, with the repository name and issue count at the top of each group, and the delete button appears only when you hover over a row.

v0.51.25

  • FixedThe menu bar owl's green eyes were barely visible; they now light up as full green circles while agents are working.

v0.51.24

  • ImprovedThe menu bar panel's Usage section shows the Claude and Codex logos, the same ones as at the top right of the Worklist, instead of colored dots.

v0.51.23

  • ImprovedThe menu bar panel's work time mountain graph now uses a fixed height scale (one agent working a full 10 minutes) and draws slopes at natural 30–60° angles with slightly rugged ridges.

v0.51.21

  • NewThe menu bar panel shows a "Work time · 3 days" mountain graph: today, yesterday and the day before are drawn as layered ridges of agent working time in 10-minute slots, under a day sky with drifting clouds (06:00–18:00) or a night sky with twinkling stars.
  • NewThe menu bar panel shows token usage for the last 7 days as daily stacked bars for Claude and Codex, read from this Mac's local logs (input + cache writes + output, cache reads excluded).
  • ImprovedThe menu bar icon's owl eyes turn green with a soft glow while agents are working, and its tooltip shows how many agents are working.
  • ImprovedThe menu bar panel is simpler: the needs-attention list, Kanban counts, Done 24h line and connection label are gone (items to check stay in Work), and each agent is one row showing its pane ID and branch.

v0.51.18

  • ImprovedThe Diagram button is enabled only when the pack has service diagrams, and the diagram list shows service diagrams only.

v0.51.17

  • ImprovedService diagrams no longer show the style picker; they use Athena's single theme.

v0.51.15

  • NewService diagrams are back: the /diagram skill (Claude /diagram · Codex $diagram) generates diagrams in the same design as Athena's own flow diagrams, with one overview of the whole structure plus two or three key feature flows per service, and a details panel that opens when a box is clicked.

v0.51.13

  • ImprovedSetup now checks whether Codex trusts Athena's hooks and explains how to approve them, and Codex lead sessions receive the same full lead instructions as Claude.

v0.51.12

  • ImprovedMerges handed off to GitHub Actions now use the plan title as the merge commit title.

v0.51.11

  • ImprovedMetrics and pane token counts now include Codex sessions, and Agent Monitor lists Codex sub-agents as sub-agent rows.

v0.51.10

  • NewRepositories that merge without pull requests now get an automatic review before merging when the change is wide (5 or more code files, 150 or more lines, or sensitive paths), including when the merge is handed off to GitHub Actions.

v0.51.9

  • ImprovedCodex reviewers run in an isolated sandbox that can only write review results, not the code under review.

v0.51.8

  • FixedCodex approval notification titles no longer include the command text, one permission request now produces a single notification per pane, and Codex questions are no longer shown twice.

v0.51.6

  • ImprovedPull request and learning reviews switch to Codex when Claude has hit its usage limit, follow the body's main tool for ordering, and record which engine made each review.

v0.51.4

  • FixedReview diffs no longer mask code values that only look like secrets, which caused reviewers to report syntax errors that did not exist.

v0.51.3

  • ImprovedNew pack windows open offset from the previous window instead of stacking exactly on top of it.

v0.51.2

  • FixedFinished-work notifications now ask GitHub for the pull request's actual state (open, draft, merged or closed) instead of showing an outdated plan value.
  • FixedSending from an outdated decision console no longer silently confirms missing decisions; the console asks you to refresh instead.

v0.51.1

  • FixedSequence diagram request labels are easier to read in both light and dark themes.

v0.51.0

  • NewCodex approval requests — commands, file changes, extra permissions and choice-style questions — can now be answered directly in Work, in all four languages, keeping the original choices and scope.

v0.50.7

  • FixedCodex panes now run with their own server so a new pane keeps its own identifier, and agent reports are delivered only to the lead session they belong to.

v0.50.6

  • ImprovedThe Board's Metrics tab shows the time distribution as six time-of-day bars with counts, expands the full task list by default, and shows each task's total elapsed time and per-stage times.

v0.50.5

  • ImprovedCodex Browser permission prompts and startup trust dialogs are now detected and announced in Work and the tray in the app's language, with a shortcut back to the pane.

See everything in v0.51.38 on GitHub

v0.47.6
