Release notes

What's new in Athena Studio

What changed in each public build of Athena Studio, newest first.

0.47v0.47.0 – v0.47.52
Nov 1–3, 2026

Updating the app or core no longer closes your panes.

v0.47.51

  • ImprovedWhen the Athena pane cannot take a message right away, for example while a question is open, agents' messages wait and are delivered in order once it is free, instead of turning into question requests.

v0.47.46

  • ImprovedSpaces shows a pane as idle once Claude has finished, even if background shells are still running. Pane title bars show the pane number and a >_ count of background shells.

v0.47.45

  • NewRestoring a pack exported with your work history now reopens Codex conversations as well, when this computer has their Codex history.
  • ImprovedThe Board's Learning tab now shows personal memory from both Claude and Codex.

v0.47.44

  • NewCodex started in the Athena folder now works as the team lead with the same rules as Claude.

v0.47.43

  • FixedReviewer panes now close automatically after review when they run in Codex.

v0.47.42

  • NewWhen Claude is not available, automatic pull request review and learning review run with Codex.

v0.47.41

  • FixedThe update popup no longer shows notes from an earlier release.

v0.47.40

  • FixedAgent Monitor no longer leaves [?] labels on older rows.

v0.47.39

  • FixedCodex agent panes no longer break after you trust their hooks.

v0.47.38

  • ImprovedPanes waiting at a question, permission, trust or model prompt now show as waiting for input in Spaces, Agent Monitor, the Board and the menu bar, and Athena does not reuse or close them while they wait.

v0.47.37

  • NewQuestions and permission prompts in Codex panes now appear in Work like Claude's, and answers to questions go back to that pane.

v0.47.36

  • FixedText sent to a pane no longer stays in its input box unsent: Athena checks that it went through and presses Enter again if needed.

v0.47.35

  • NewAgents and reviewers can now run as Codex panes in the repository's workspace.

v0.47.32

  • NewWhen Claude and Codex are both signed in, Athena asks which tool to start and remembers your choice. Starting the other tool in the Athena workspace updates that choice.

v0.47.31

  • ImprovedCodex sessions now use the same commit, secret and process protection hooks as Claude sessions.
  • ImprovedAgent Monitor now shows Codex sessions alongside Claude sessions, including their model, tool activity and summaries.

v0.47.30

  • ImprovedAfter automatic review reaches its round limit, the final fixes now get a short review of the changed code before merging. Blocking findings or a failed review stop the merge.

v0.47.28

  • FixedWhen Athena sends new work to an idle agent pane, the new branch now starts in the folder that pane is actually working in, and Athena refuses if that folder is the repository's main checkout.
  • FixedWhen another pane answers an agent's question in chat on its behalf, the answer now reaches the pane that asked.

v0.47.27

  • NewDrag a pane's header onto another pane in the same tab to move it there. It lands on the top, bottom, left or right side nearest the pointer, with a preview of where it will go. Programs in the pane keep running, and Esc cancels.

v0.47.26

  • NewA repository can hand full verification and merging to GitHub Actions, so agents move on to the next task without waiting. It is off by default and works for repositories with auto PR off that merge without asking. The Board card shows the Actions status, and failures are sent back to the agent's pane.

v0.47.25

  • FixedThe agent list in the menu bar panel no longer shows a horizontal scrollbar, and its scrollbar now matches the dark panel.

v0.47.24

  • NewThe Board has a light and dark mode button. Your choice is remembered; until you pick one, it follows your system setting.

v0.47.23

  • ImprovedThe Board's Metrics tab shows time from start to first merge as a median, with the average and p75, and compares it with the previous period. It adds a stage for waiting on your answers and can filter by start date and by whether work was reviewed.

v0.47.22

  • ImprovedAgents now check only the parts they changed while working and run full verification once, when the task ends.

v0.47.21

  • FixedThe Board now reads Athena's Claude memory from the folder Claude Code actually uses, so the memory list no longer shows up empty.

v0.47.20

  • FixedSeveral decision consoles no longer overwrite each other. Each opens in its own tab in the side browser, a new one waits in a tab behind the one you are viewing, and sending one closes only its tab and moves to the next.

v0.47.15

  • FixedSwitching panes no longer flashes a loading state or the wrong title in the right sidebar: the previous content stays until the new one is ready.

v0.47.14

  • ImprovedAgent Monitor rows now show the model that answered, and times include seconds.

v0.47.13

  • Fixed⌘⇧J and ⌘⇧K now move pane focus even when another app has claimed those keys, while an Athena window is focused.

v0.47.12

  • NewPermission prompts in a pane now appear in Work with a way to jump to that pane. You still allow or deny in the pane, and the Work item closes once you do.
  • ImprovedQuestions in the Athena pane now also appear in Work while you are looking at the pane, so you can answer in either place.

v0.47.8

  • ImprovedPane focus shortcuts changed from ⌘⌥ + arrow keys to ⌘⇧I J K L (up, left, down, right).

v0.47.7

  • FixedWhen auto PR is off, Athena now blocks opening a pull request by mistake and points to the direct merge instead.

v0.47.6

  • FixedWhen an agent asks you to pick an option in the Athena pane and you are not looking at it, the question now goes to Work so you can answer it there.

v0.47.1

  • NewA pack can allow specific commands for its repository's agent panes with permissionsAllow, so they run without a permission prompt.
  • FixedAn agent's "done" notification now waits until its background commands have finished.
  • FixedAn agent pane can now push review fixes to its open pull request even when no request is waiting on that pull request.
  • FixedA decision request without a decision console now stays a decision and opens as a question popup, so you can answer it in the app.

v0.47.0

  • NewUpdating the app or core no longer closes your panes: running panes switch to the new code and keep going.
  • NewIf panes are running an older version that cannot switch, Athena lists the panes that would close and closes them only when you choose to. Otherwise you can keep using them as they are.

8 more small changes and fixes · See everything in v0.47.52 on GitHub

0.46v0.42.3 – v0.46.4
Nov 1, 2026

Agents read your repository rules, and small pull requests take a fast path.

v0.46.1

  • FixedAutomatic merge no longer goes ahead if the pull request's base changed while it was waiting.

v0.46.0

  • NewAthena finds each repository's rule documents and loads their full text into agent sessions. You can add or exclude documents in the pack.

v0.44.0

  • NewSmall pull requests take a ⚡ fast path: one reviewer and one review, and after one round of fixes the work merges once verification and the conflict check pass. A repository can turn this off.

v0.43.0

  • ImprovedThe Metrics tab shows time by stage (work, verification, review, merge wait), review rounds and fixes per merge.

6 more small changes and fixes · See everything in v0.46.4 on GitHub

0.42v0.40.4 – v0.42.2
Oct 31, 2026

Updates open the window first and finish in the background.

v0.42.1

  • Security patchUpdated Electron to 44.10.0, so the Node built into the app is now the security release 24.22.1.

v0.41.1

  • FixedSplitting a pane or closing one no longer resizes the neighbouring panes' terminals by a rough guess.

v0.41.0

  • ImprovedThe window opens first on restart, and the core update runs in the background: the tab bar shows "core update in progress", and a result popup appears when it finishes. Pack commands, new agent panes and catch-up wait until the update is done.

v0.40.9

  • ImprovedThe core update popup shows short kind chips, and an update that only changes the last version number now lists its recent changes too.

0.40v0.32.5 – v0.40.3
Oct 30, 2026

Choose per repository whether Athena opens the pull request.

v0.40.0

  • NewTurning auto PR off for a repository skips the pull request and review and merges the work branch straight into the base branch once verification passes.

v0.36.1

  • ImprovedThe second slot for heavy commands now also waits until CPU load is below the core count.

v0.36.0

  • NewChoose per repository, in Settings, whether Athena opens a pull request, runs the automatic review, and merges. Merging can be automatic, ask first in Work, or left to you.

v0.35.2

  • FixedAn agent's question no longer disappears from the Work popup. Unanswered questions stay until the agent acknowledges or cancels them, and a failure to read requests is shown instead of an empty list.

v0.35.0

  • ImprovedHeavy commands such as builds and tests can run two at a time. The second slot opens only when memory is free.

v0.33.0

  • NewWhen a delegated agent finishes a turn, Athena is notified automatically. The agent's "next prompt" suggestion is turned off, so a leftover suggestion is no longer mistaken for text you were typing.

v0.28.9
