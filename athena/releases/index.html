Release notes

What's new in Athena Studio

What changed in each public build of Athena Studio, newest first.

0.25v0.25.1
Oct 29, 2026

Drag files in from Finder to enter their paths.

  • NewDrag files or folders onto a pane to paste their paths into its input line. Nothing is sent until you press Enter.
  • NewWhen a pull request is opened, Athena warns if the tests added in it would also pass without the change. It never blocks the PR.
  • ImprovedLight tasks run on a lighter model, and a review after "needs changes" can use a stronger one.

6 more small changes and fixes · See everything in v0.25.1 on GitHub

0.19v0.19.2
Oct 29, 2026

Resize the panels around your work.

  • NewDrag the edges to resize the workspace list, the Explorer, and the monitor.
  • FixedDragging the border between panes is no longer blocked by a scrollbar.
  • FixedThe Work and Settings buttons no longer stay disabled after the start screen.

4 more small changes and fixes · See everything in v0.19.2 on GitHub

0.17v0.17.6
Oct 29, 2026

The Mac app now updates itself.

  • NewPress Update in Settings (⚙) to download, verify, and restart. If it fails, your current version keeps running.
  • NewAthena can watch a repository’s GitHub issues and pick up new ones as work.
  • ImprovedAlerts show only the things you need to decide.

5 more small changes and fixes · See everything in v0.17.6 on GitHub

0.15v0.15.8
Oct 28, 2026

The first public release, as a Mac app.

  • NewDownload for Apple Silicon or Intel Macs (macOS 13 Ventura or later).
  • NewSigned and notarized by Apple, so it opens without a security warning.

2 more small fixes · See everything in v0.15.8 on GitHub

Development builds before the first public release (0.2 – 0.13)
0.2 – 0.13Oct 26–28, 2026
  • Dev buildsDevelopment builds before the first public release. Along the way came automatic pull request review with Claude and Codex, a model choice for each role, the work board and pane details, the agent monitor, and repository names, images and logos.
