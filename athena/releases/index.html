Release notes

What's new in Athena Studio

What changed in each public build of Athena Studio, newest first.

0.46 · 0.47v0.47.2
Nov 1, 2026

Agents read your repository rules, and small pull requests take a fast path.

  • NewAthena finds each repository's rule documents and loads their full text into agent sessions. You can add or exclude documents in the pack.
  • NewSmall pull requests take a ⚡ fast path: one reviewer and one review, and after one round of fixes the work merges once verification and the conflict check pass. A repository can turn this off.
  • NewUpdating the app or core no longer closes your panes: running panes switch to the new code and keep going.
  • NewIf panes are running an older version that cannot switch, Athena lists the panes that would close and closes them only when you choose to. Otherwise you can keep using them as they are.
  • NewA pack can allow specific commands for its repository's agent panes with permissionsAllow, so they run without a permission prompt.
  • ImprovedThe Metrics tab shows time by stage (work, verification, review, merge wait), review rounds and fixes per merge.
  • FixedAutomatic merge no longer goes ahead if the pull request's base changed while it was waiting.

0.42v0.42.2
Oct 31, 2026

Updates open the window first and finish in the background.

  • ImprovedThe window opens first on restart, and the core update runs in the background: the tab bar shows "core update in progress", and a result popup appears when it finishes. Pack commands, new agent panes and catch-up wait until the update is done.
  • ImprovedThe core update popup shows short kind chips, and an update that only changes the last version number now lists its recent changes too.
  • FixedSplitting a pane or closing one no longer resizes the neighbouring panes' terminals by a rough guess.
  • Security patchUpdated Electron to 44.10.0, so the Node built into the app is now the security release 24.22.1.

2 more small fixes · See everything in v0.42.0 on GitHub

0.40v0.40.3
Oct 30, 2026

Choose per repository whether Athena opens the pull request.

  • NewChoose per repository, in Settings, whether Athena opens a pull request, runs the automatic review, and merges. Turning auto PR off skips the pull request and review and merges the work branch straight into the base branch once verification passes. Merging can be automatic, ask first in Work, or left to you.
  • NewWhen a delegated agent finishes a turn, Athena is notified automatically. The agent's "next prompt" suggestion is turned off, so a leftover suggestion is no longer mistaken for text you were typing.
  • ImprovedHeavy commands such as builds and tests can run two at a time. The second slot opens only when memory is free and CPU load is below the core count.
  • FixedAn agent's question no longer disappears from the Work popup. Unanswered questions stay until the agent acknowledges or cancels them, and a failure to read requests is shown instead of an empty list.

10 more small changes and fixes · See everything in v0.40.3 on GitHub

0.32v0.32.4
Oct 30, 2026

See what changed, right in the app after each update.

  • NewAfter Athena's core updates, an in-app popup shows the previous and new versions, what's new, and how the update went, with working sessions listed by agent name.
  • NewIn packs without the Athena Studio repository, a bug report about Athena itself becomes a GitHub issue draft with private details hidden. Athena shows you the draft and opens it on GitHub for you to review and submit.
  • ImprovedAthena hands a new task to an idle agent pane for the same repository instead of opening another pane.
  • ImprovedAgent panes start without MCP servers, so each reply uses fewer tokens. Reviewer panes keep them.
  • ImprovedThe PR automation switches in Settings are named for what they turn on: "Auto PR · review" and "Merge right after approval". The warning line under them is gone.
  • FixedThe commit guard no longer wrongly blocks Athena's own commit script when the message spans several lines or the path uses ~ or a variable.
  • FixedIn repositories with auto-merge on, agents no longer ask you to merge a pull request they opened. Automatic review takes it through to merge, and the agent reports its state.

See everything in v0.32.4 on GitHub

0.28v0.28.7
Oct 29, 2026

Answer an agent's question right from Work.

  • NewWhen an agent asks you a question in its pane, the question also shows up as a request in Work, so you can pick an answer there.
  • ImprovedReports to the Athena pane arrive in one step. If the Athena pane can't be found, the report is kept as a request instead of being lost.
  • FixedThe side browser no longer flashes white when the board or a decision console opens.
  • FixedOpening a decision console from the Work popup now uses the side browser instead of your outside browser.
  • FixedIn the agent monitor, Athena's own session shows as athena instead of a folder name.
  • FixedWork, Settings, and Board menu popups are no longer hidden while the side browser is open.

Drag files in from Finder to enter their paths.
