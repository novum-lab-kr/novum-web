Athena Studio
기능 문서 업데이트 내역 다운로드

AI 에이전트를 조율하고,
더 나은 소프트웨어를 완성하다.

Athena Studio는 AI 코딩 에이전트를 돌리는 맥 앱입니다. 팀 리드 Athena에게 할 일을 말하면 계획을 세워 레포마다 에이전트를 붙이고, 정할 게 생기면 나에게 묻습니다. 나는 diff를 보고 머지하면 됩니다.

macOS용 다운로드 사용 흐름 보기 ↓

무료 · macOS 13 이상 · Apple Silicon / Intel · Claude Code 또는 Codex 필요

설치 → 레포 연결 → Athena에게 요청 → 질문에 답하기 → PR 확인

왜 Athena Studio입니까

레포 여러 개를 한 번에

요청 하나가 web · api · mobile에 걸쳐도 됩니다. Athena가 나누고, 레포마다 에이전트가 자기 브랜치에서 동시에 일합니다.

나는 정할 때만

에이전트의 질문은 [작업] 목록 하나로 모입니다. 누가 나를 기다리는지 터미널을 뒤질 필요가 없습니다.

머지 전에 확인

에이전트는 PR을 열기 전에 테스트를 돌립니다. 자동 리뷰를 켠 레포에서는 머지 전에 고칠 점을 받아 고칩니다.

레포를 점점 알아 갑니다

작업이 끝날 때 남긴 노트를 그 레포의 다음 작업이 읽습니다.

01

요청 하나를 레포마다 나누는 Athena

Athena가 계획을 세우고 담당 에이전트에게 작업을 맡깁니다. 에이전트는 각자 브랜치에서 구현하고, 결정이 필요하면 질문을 남깁니다.

데모 요청(읽기 쉽게 다듬었습니다)장바구니에 담고 구매하지 않는 손님이 많아. web에 저장한 장바구니를 알려 주는 배너를 넣고, mobile에서도 쓸 수 있게 api의 주문 내역을 페이지로 나눠 줘.

02

에이전트가 하는 일을 한 줄씩 지켜봅니다.

창 아래 에이전트 모니터에 각 에이전트의 로그가 실시간으로 올라옵니다. 읽고 고친 파일, 실행한 명령, 남긴 말이 나오고, 줄마다 초 단위 시간과 그 줄을 쓴 모델 이름이 붙습니다.

데모 로그입니다. 칩을 누르면 그 에이전트의 줄만 봅니다. 모니터는 Claude Code 에이전트를 보여 주며, Codex 에이전트는 나오지 않습니다.

03 · api · 주문 내역

에이전트의 질문이 올라오는 [작업]

주문 내역을 한 페이지에 20개씩 보여 주도록 하시겠습니까, 50개씩 보여 주도록 하시겠습니까? [작업]에서 질문에 답하면 에이전트가 이어서 진행합니다. 질문이 오면 메뉴 막대에 빨간 점도 뜹니다.

데모에서는 20개를 골랐습니다. 화면은 영어 데모입니다.

04 · web · 장바구니 알림

바뀐 코드와 테스트 결과를 나란히

터미널 옆에서 diff를 읽고 검증 결과를 확인한 뒤 머지합니다. PR 자동 리뷰 · 머지는 레포마다 설정하고, 머지 전 확인을 남겨 둘 수 있습니다.

데모의 web 레포 장바구니 작업: 테스트 6개 통과와 CartPage.tsx 변경 내역.

05

이미 쓰는 코딩 에이전트와 함께

Athena Studio는 이미 쓰는 Claude Code나 Codex를 그대로 돌리고, 그 위에 팀 리드 · 계획서 · 리뷰를 얹습니다.

코드가 가는 곳
앱은 코드와 파일을 Novum Lab 서버로 보내지 않습니다. AI 요청은 쓰는 제공자에게 가고, 푸시는 내 GitHub로 갑니다. 자세히
비용
Athena Studio는 무료입니다. AI 사용료는 쓰는 Claude나 Codex 요금제대로 나갑니다.
언어
영어 · 한국어 · 일본어 · 중국어. 앱과 에이전트에 같이 적용됩니다. 일감 화면(⌘2)은 아직 한국어만 있습니다.
필요한 것
macOS 13 이상. PR 자동 리뷰에는 Claude Code가 필요합니다. 전체 조건
