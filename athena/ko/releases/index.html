Athena Studio의 새 소식

Athena Studio 공개판마다 바뀐 것을 최신 순으로 적었습니다.

0.47v0.47.0 – v0.47.10
2026년 11월 1일

앱이나 코어를 업데이트해도 pane 이 닫히지 않습니다.

  • 새 기능앱이나 코어를 업데이트해도 pane 이 닫히지 않습니다. 돌고 있는 pane 은 새 코드로 바뀌어 그대로 이어집니다.
  • 새 기능pane 이 바꿀 수 없는 예전 버전으로 돌고 있으면, 닫히는 pane 목록을 보여 주고 직접 고를 때만 닫습니다. 고르지 않으면 지금 그대로 계속 쓸 수 있습니다.
  • 새 기능팩의 permissionsAllow 로 그 레포 에이전트 pane 에 특정 명령을 허용하면, 권한을 묻지 않고 실행합니다.
  • 개선포커스 이동 단축키가 ⌘⌥ + 방향키에서 ⌘⇧I J K L(위, 왼쪽, 아래, 오른쪽)로 바뀌었습니다.
  • 수정에이전트의 끝 알림은 백그라운드 명령이 끝난 뒤에 옵니다.
  • 수정에이전트 pane 이 열린 PR 에 리뷰 수정을 올릴 수 있습니다. 그 PR 에 기다리는 요청이 없어도 됩니다.
  • 수정결정 콘솔이 없는 결정 요청은 결정으로 남고 질문 팝업으로 열려, 앱에서 바로 답할 수 있습니다.
  • 수정자동 PR 이 꺼진 레포에서는 실수로 PR 을 여는 것을 막고 직접 머지를 안내합니다.
  • 수정에이전트가 Athena pane 에서 선택지를 고르라고 물었는데 그 pane 을 보고 있지 않으면, 질문이 작업으로 가서 거기서 답할 수 있습니다.

0.46v0.46.4
2026년 11월 1일

에이전트가 레포 규칙을 읽고, 작은 PR 은 빠른 길로 갑니다.

  • 새 기능아테나가 레포마다 규칙 문서를 찾아 원문 그대로 에이전트 세션에 싣습니다. 팩에서 문서를 더하거나 뺄 수 있습니다.
  • 새 기능작은 PR 은 ⚡ 빠른 길로 갑니다. 리뷰어 하나가 한 번만 리뷰하고, 수정을 한 번 거치면 검증과 충돌 확인만 통과해도 머지됩니다. 레포마다 끌 수 있습니다.
  • 개선지표 탭에서 구간별 시간(작업 · 검증 · 리뷰 · 머지 대기), 리뷰 라운드, 머지당 수정을 볼 수 있습니다.
  • 수정자동 머지를 기다리는 동안 PR 의 base 가 바뀌면 머지하지 않습니다.

0.42v0.42.2
2026년 10월 31일

업데이트 뒤에 창이 먼저 열리고, 코어 갱신은 뒤에서 끝납니다.

  • 개선다시 시작하면 창이 먼저 열리고 코어 업데이트는 뒤에서 진행됩니다. 탭 줄에 "코어 업데이트 진행 중"이 보이고, 끝나면 결과 팝업이 뜹니다. 팩 명령 · 새 에이전트 pane · 이어받기는 업데이트가 끝날 때까지 기다립니다.
  • 개선코어 업데이트 팝업에 짧은 종류 표시가 붙고, 마지막 버전 숫자만 바뀐 업데이트도 최근 변경을 보여 줍니다.
  • 수정pane 을 나누거나 닫을 때 이웃 pane 의 터미널 크기를 대충 짐작으로 바꾸지 않습니다.
  • 보안 패치Electron 을 44.10.0 으로 올려, 앱에 들어 있는 Node 가 보안 릴리스 24.22.1 이 됐습니다.

0.40v0.40.3
2026년 10월 30일

레포마다 아테나가 PR 을 열지 직접 고르세요.

  • 새 기능설정에서 레포마다 아테나가 PR 을 열지, 자동 리뷰를 돌릴지, 머지할지 고를 수 있습니다. 자동 PR 을 끄면 PR 과 리뷰 없이 검증이 통과한 작업 브랜치를 바로 기준 브랜치에 머지합니다. 머지는 자동으로 하거나, 작업 화면에서 먼저 묻거나, 직접 할 수 있습니다.
  • 새 기능위임한 에이전트가 한 차례를 마치면 아테나에 자동으로 알려 줍니다. 에이전트의 "다음 프롬프트" 제안은 꺼서, 남은 제안을 직접 입력하던 글로 착각하지 않습니다.
  • 개선빌드나 테스트 같은 무거운 명령을 두 개까지 동시에 돌릴 수 있습니다. 두 번째 자리는 메모리가 넉넉하고 CPU 부하가 코어 수보다 낮을 때만 열립니다.
  • 수정에이전트의 질문이 작업 팝업에서 사라지지 않습니다. 답하지 않은 질문은 에이전트가 확인하거나 취소할 때까지 남고, 요청을 읽지 못하면 빈 목록 대신 오류를 보여 줍니다.

0.32v0.32.4
2026년 10월 30일

업데이트 뒤 바뀐 점을 앱 안에서 바로 확인

  • 새 기능아테나 코어가 업데이트되면 앱 안 팝업에 이전 · 새 버전, 업데이트 내역, 업데이트 결과가 보입니다. 일하던 세션은 에이전트 이름으로 보입니다.
  • 새 기능Athena Studio 레포가 없는 팩에서 아테나 자체 버그를 올리면 개인 정보를 가린 GitHub 이슈 초안이 됩니다. 아테나가 초안을 보여 주고 GitHub 에서 열어 주면, 확인하고 직접 올립니다.
  • 개선같은 레포 에이전트 pane 이 쉬고 있으면 새 pane 을 열지 않고 그 pane 에 새 작업을 이어 보냅니다.
  • 개선에이전트 pane 을 MCP 서버 없이 띄워서 답마다 쓰는 토큰이 줄어듭니다. 리뷰어 pane 은 그대로 씁니다.
  • 개선설정의 PR 자동화 스위치 이름이 켜지는 것 그대로 바뀌었습니다: "자동 PR · 리뷰", "승인되면 바로 머지". 그 아래 경고 줄은 없앴습니다.
  • 수정커밋 메시지가 여러 줄이거나 경로에 ~ 나 변수를 쓰면 커밋 보호 훅이 아테나의 커밋 스크립트를 잘못 막던 문제를 고쳤습니다.
  • 수정자동 머지를 켠 레포에서 에이전트가 자기가 연 PR 을 머지해 달라고 하지 않습니다. 자동 리뷰가 머지까지 이어 가고, 에이전트는 PR 상태를 알려 줍니다.

0.28v0.28.7
2026년 10월 29일

에이전트의 질문을 작업 화면에서 바로 답합니다

  • 새 기능에이전트가 pane에서 질문하면 작업 화면에도 요청으로 나타나, 거기서 답을 고를 수 있습니다.
  • 개선Athena pane으로 가는 보고가 한 번에 도착합니다. Athena pane을 찾지 못하면 보고를 잃지 않고 요청으로 남깁니다.
  • 수정보드나 결정 콘솔을 열 때 옆 브라우저가 하얗게 번쩍이지 않습니다.
  • 수정작업 화면의 팝업에서 결정 콘솔을 열면 바깥 브라우저 대신 옆 브라우저로 열립니다.
  • 수정에이전트 모니터에서 Athena 자신의 세션이 폴더 이름 대신 athena로 표시됩니다.
  • 수정옆 브라우저가 열려 있어도 작업 · 설정 · 보드 메뉴 팝업이 가려지지 않습니다.
