Athena Studio의 새 소식

Athena Studio 공개판마다 바뀐 것을 최신 순으로 적었습니다.

0.28v0.28.7
2026년 10월 29일

에이전트의 질문을 작업 화면에서 바로 답합니다

  • 새 기능에이전트가 pane에서 질문하면 작업 화면에도 요청으로 나타나, 거기서 답을 고를 수 있습니다.
  • 개선Athena pane으로 가는 보고가 한 번에 도착합니다. Athena pane을 찾지 못하면 보고를 잃지 않고 요청으로 남깁니다.
  • 수정보드나 결정 콘솔을 열 때 옆 브라우저가 하얗게 번쩍이지 않습니다.
  • 수정작업 화면의 팝업에서 결정 콘솔을 열면 바깥 브라우저 대신 옆 브라우저로 열립니다.
  • 수정에이전트 모니터에서 Athena 자신의 세션이 폴더 이름 대신 athena로 표시됩니다.
  • 수정옆 브라우저가 열려 있어도 작업 · 설정 · 보드 메뉴 팝업이 가려지지 않습니다.

0.25v0.25.1
2026년 10월 29일

Finder에서 끌어다 놓은 파일의 경로 입력

  • 새 기능pane에 파일이나 폴더를 끌어다 놓으면 경로가 입력줄에 붙습니다. Enter를 누르기 전에는 아무것도 보내지 않습니다.
  • 새 기능PR을 열 때, 함께 넣은 테스트가 변경 없이도 통과하는지 알려 줍니다. PR을 막지는 않습니다.
  • 개선가벼운 일감은 더 가벼운 모델로 돌고, '고쳐야 함' 뒤 리뷰는 더 강한 모델을 쓸 수 있습니다.

0.19v0.19.2
2026년 10월 29일

작업 화면 둘레 칸의 크기 조절

  • 새 기능가장자리를 끌어 작업 공간 목록 · Explorer · 모니터의 크기를 바꿉니다.
  • 수정pane 사이 경계를 끌 때 스크롤바에 막히지 않습니다.
  • 수정시작 화면을 나온 뒤 [일감] · [설정] 버튼이 꺼진 채로 남지 않습니다.
