작업 공간

레포마다 따로 있는 작업 공간

왼쪽에는 레포와, 그 안에서 일하는 브랜치 · 에이전트가 있습니다. 가운데는 탭과 분할 터미널이고, 에이전트마다 이름 붙은 자기 pane이 있습니다. 오른쪽은 Explorer입니다.

  • 작업마다 탭, 탭 안은 pane으로 나눕니다
  • 에이전트 pane은 에이전트 · 브랜치 이름, Athena pane은 계획 중인 일 이름
  • 창을 닫아도 모두 계속 돌고, 다시 열면 같은 탭 · 같은 배치
  • 에이전트를 부르면 가장 큰 pane을 긴 쪽으로 나눠 자리를 잡습니다(다음 업데이트부터)
  • 레포에 보여 줄 이름과 이미지를 붙이고, 팩으로 팀과 나눕니다
진행과 질문

에이전트별 진행 상황과 나에게 필요한 것

에이전트 모니터

창 아래 피드에 각 에이전트가 읽고 고친 파일, 실행한 명령, 남긴 말이 올라옵니다. 어느 작업 공간에서도 보입니다.

작업

에이전트가 나를 찾으면 그 질문이나 결정이 [작업] 맨 위에 올라옵니다. 그 아래로 진행 중인 일과 지난 하루 동안 끝난 일이 있습니다. 거기서 답하면 에이전트가 멈춘 데서 이어서 합니다.

pane 상세

에이전트 머리 줄에서 상세를 열면, 터미널 크기는 그대로 둔 채 창 위로 패널이 나옵니다. 에이전트가 나에게 바라는 것, 막힌 것, 계획서와 PR을 보여 줍니다.

메뉴 막대

맥 메뉴 막대에 Athena Studio 부엉이가 있습니다. 빨간 점이 뜨면 열린 질문이나 막힌 계획이 있다는 뜻입니다. 부엉이를 누르면 에이전트마다 지금 상태가 보입니다.

결정과 코드

정할 건 정하고, 코드는 읽기

정할 게 여러 개일 때의 결정 콘솔

계획에 정할 게 여러 개면 Athena가 결정 콘솔로 정리합니다. 선택지마다 장단점과 추천이 붙습니다. 콘솔은 에이전트 터미널 옆 브라우저 칸에 열리고, 내가 고르면 에이전트가 이어서 일합니다.

  • 필수 · 선택 결정, 추천 선택지 표시
  • 옆 브라우저(⌘⇧B)로 계획서 · 결정 콘솔 · 로컬 테스트 화면
  • 로그인은 따로, 샌드박스, http · https만

터미널 옆에서 작업 읽기

지금 작업 공간의 파일과 git 변경을 둘러보고 터미널 옆에 엽니다. 바뀐 파일은 diff로 열립니다.

  • git 상태(M · U · A · D · R)가 붙은 파일 트리와 변경 목록
  • 문법 강조 · 줄 번호 · 이미지
  • 작업 공간 폴더 안만 읽습니다. Esc로 뷰어 닫기
리뷰와 학습

리뷰를 거치는 PR, 남는 배운 것

PR 자동 리뷰와 수정

자동 리뷰를 켠 레포에서는 에이전트가 푸시하면 그 레포 하나짜리 PR을 바로 리뷰합니다. 의견은 에이전트에게 돌아가고 최대 3라운드까지 고친 뒤 머지 단계로 넘어갑니다. 큰 diff는 코드부터 보고, 앞서 받은 승인은 이어집니다.

  • 기본은 꺼짐, 설정에서 레포마다 켭니다
  • ‘머지 전에 확인 받기’를 켜 두면 마지막 클릭은 내가
  • 에이전트 · 리뷰어처럼 역할마다 모델을 고릅니다
  • 리뷰 결과와 머지는 계획서와 PR에 기록됩니다

고른 노트만, 다음 작업으로

머지가 끝나면 학습 리뷰가 리뷰 의견이나 QA 결과처럼 작업 중에 나온 내용으로 노트를 제안합니다. [학습]에서 내가 고른 것만 그 레포의 학습 노트로 남고, 에이전트는 다음 작업을 시작할 때 이 노트를 읽습니다.

학습 · api
학습 리뷰가 제안 · 내가 고름
+ 목록 API는 createdAt 커서 페이지 나누기, 한 페이지 20개.
+ 응답 모양: { items, nextCursor }. mobile도 같은 모양을 읽습니다.
→ api의 다음 일이 읽습니다
팩과 언어

회사마다 팩 하나, 내가 쓰는 언어로

회사마다 팩 하나씩

팩에는 한 회사의 레포 · 에이전트 · 라우팅 규칙이 들어 있습니다. 팩마다 따로 돌아서, 바꿔도 다른 팩의 일은 멈추지 않습니다.

  • 내 맥의 레포로 팩을 만들거나, 파일 · 폴더 · git 레포에서 가져옵니다
  • 팩을 바꿔도 다른 팩의 에이전트는 하던 일을 계속합니다
  • 에이전트 대화와 끝나지 않은 브랜치까지 내 작업과 함께 내보내고, 나중에 되살립니다
