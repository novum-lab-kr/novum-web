macOS용 Athena Studio

버전 0.42.0 · 2026년 10월 31일 · 바뀐 것

macOS 13 Ventura 이상에서 무료로 쓸 수 있습니다. Apple의 서명 · 공증을 받았습니다.

2020년 이후 대부분의 맥 Apple Silicon M1 · M2 · M3 · M4 이후 .dmg 받기 v0.42.0
예전 맥 Intel Intel 프로세서 맥 .dmg 받기 v0.42.0

어느 쪽인지 모르겠다면 → 이 Mac에 관하여 에서 ‘칩: Apple M…’이면 Apple Silicon, ‘프로세서: Intel’이면 Intel입니다.

필요한 것

설치 전에 확인할 것

  • macOSmacOS 13 Ventura 이상
  • AI 에이전트Claude Code 또는 Codex에 내 계정으로 로그인해 두십시오.
  • git · Python 3없으면 처음 켤 때 macOS가 설치를 띄워 줍니다. 미리 설치하려면 터미널에서 xcode-select --install
  • Node.jsAthena의 스크립트가 씁니다. 설치한 Node 는 22.x 는 22.23.4, 24.x 는 24.22.1, 26.x 는 26.12.1 이상이어야 해요. 앱에 들어 있는 Node 는 24.22.1 이에요.
  • GitHub내 레포에 접근할 수 있어야 합니다. PR 올리기와 자동 리뷰에는 gh CLI가 필요합니다.

설치하셨습니까? 문서의 시작하기에서 첫 팩과 첫 요청까지 안내합니다.

Athena Studio를 설치하면 최종 사용자 사용권 계약에 동의하는 것으로 봅니다.
