Orchestrate Agents.
Ship Better Software.

Athena Studio is a Mac app for running AI coding agents. Athena, the team lead, first reads your repositories and makes an agent for each one, with its rules, notes and check script. Then tell Athena what you want: it writes a plan, hands each part to that repository's agent and asks you when something needs deciding. You read the diff and merge.

Why Athena Studio

An agent that knows each repository

Athena reads each repository and makes its agent, with rules, structure notes, a gotchas notebook and a check script. Anything it can't confirm is marked for you to check, not guessed. Notes you keep after a task are read by the next one.

Several repositories at once

One request can touch web, api and mobile. Athena splits it, and an agent works on each repository at the same time, on its own branch.

You step in only to decide

Agents bring their questions to one Work list, so you don't scroll through terminals to find who is waiting on you.

Checked before it merges

Agents run tests before they open a pull request. In repositories where you turn it on, automatic review asks for fixes before the merge.

How it works

Every task gets a plan, its own worktree and a check before it ships.

First setup runs once, when you create a pack. After that, every request goes through the same five steps behind the screens.

  1. 0First setup, onceAthena reads each repository's production branch without changing it. It makes an agent for each repository with its rules, structure notes, a gotchas notebook and a check script, and writes the routing table that says which request goes to which repository. Anything it can't confirm is marked for you to check, not guessed.
  1. 1RequestAsk in plain words. Athena reads the pack's routing table to see which repositories the request touches and which agent handles each one.
  2. 2PlanEvery change starts from a written plan. If something is yours to decide, or several repositories must line up, the plan comes with a decision console, and no work is handed out until you confirm.
  3. 3A worktree per taskEach task gets a new branch in its own git worktree, a separate working folder. Your main checkout stays untouched, and several tasks run side by side.
  4. 4Checks and reviewAgents check what they changed as they go, then run the full verification once at the end, on your Mac or, if you turn it on, in GitHub Actions. Wide changes also get a reviewer agent.
  5. 5PR and mergeThe branch becomes a draft PR, or merges straight in, as each repository is set. Automatic review can ask for fixes, and you can confirm each merge.

Where your code goes
The app doesn't send your code or files to Novum Lab. If you turn on the mobile connection, they pass through the Relay server end-to-end encrypted between your Mac and your mobile device, and the Relay server doesn't read or store them. AI requests go to the provider you use, and pushes go to your GitHub. Details

06 · Mobile

Your agents, on mobile too.

The Athena mobile app connects to Athena Studio on your Mac, so you can answer your agents when you're away from your desk. It connects while Athena Studio is running on your Mac. The relay in between passes only encrypted data and doesn't read or store your terminals or requests.
