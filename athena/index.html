Your AI coding team, in one window.

Ask Athena, the team lead, to plan and split work across your repositories. Answer the agents' questions, and check code changes and PRs in the same Mac app.

Get launch updates See the workflow ↓

macOS 13+ · Apple Silicon / Intel · Claude Code or Codex · Not released yet (the button opens your email app)

Install → connect repositories → ask Athena → answer questions → review the PR

01

Ask Athena. The work is split by repository.

Athena writes the plan and hands each part to that repository's agent. Each agent works on its own branch and asks you when a decision is needed.

Request from our demo projectCustomers keep abandoning carts. Add a saved-cart reminder on web, and paginate order history in api so mobile can use it too.

02 · api · order history

Answer agent questions without leaving the app.

Should order history show 20 or 50 items per page? The question appears in Work and a red dot shows in the menu bar. Send your answer and the agent continues.

In the demo, 20 was chosen. The screen is the English demo.

03 · web · cart reminder

See the code change beside the test results.

Read the diff next to the terminal and check the results before you merge. Automatic PR review and merging are set per repository, with an option to confirm before each merge.

Demo cart task in the web repository: 6 tests passing and the CartPage.tsx diff.

04

Connect your repositories and get started.

Install the app and group the repositories you work with into a pack. Then send your first request in the athena workspace.

  1. Install Claude Code or Codex signed in, plus git, Python 3 and Node.js.
  2. Make a pack New Pack on first launch, or import your team's pack.
  3. Ask Athena Describe the change in the athena workspace.
  4. Answer questions Open the question in Work and answer it.
  5. Review and merge Check the diff and tests, then merge the PR.
