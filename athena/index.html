AI writes the code.
Athena builds the team.

Athena Studio is a Mac app for running AI coding agents. Tell Athena, the team lead, what you want. It writes a plan, puts an agent on each repository and asks you when something needs deciding. You read the diff and merge.

Install → connect repositories → ask Athena → answer questions → review the PR

Why Athena Studio

Several repositories at once

One request can touch web, api and mobile. Athena splits it, and an agent works on each repository at the same time, on its own branch.

You step in only to decide

Agents bring their questions to one Work list, so you don't scroll through terminals to find who is waiting on you.

Checked before it merges

Agents run tests before they open a pull request. In repositories where you turn it on, automatic review asks for fixes before the merge.

Learns each repository

Notes you keep after a task are read by the next task in that repository.

01

Athena splits one request across your repositories.

Athena writes the plan and hands each part to that repository's agent. Each agent works on its own branch and asks you when a decision is needed.

04

It works with the coding agent you already use.
