Run a team of AI coding agents from one Mac app.

Athena Studio runs Athena, a team lead agent that writes a plan and hands each part to the coding agent for that repository. You watch their terminals side by side, answer their questions and review the pull requests they open. It uses Claude Code or Codex with your own account.

How to use it

Once it's released, going from install to a merged pull request looks like this.

  1. 01InstallInstall the app. Claude Code or Codex needs to be installed and signed in with your account, along with git, Python 3 and Node.js.
  2. 02Make a packOn first launch, choose New Pack and pick repositories on your Mac. A pack is the set of repositories and agent settings you work with. If your team already has one, import it.
  3. 03Ask AthenaIn the athena workspace, describe the change you want. Athena writes a plan and hands it to the agent for each repository involved.
  4. 04Answer questionsWhen an agent needs a decision, a red dot appears in the menu bar and the question shows up in Work. Open it, choose an answer, and the agent continues.
  5. 05Review and mergeCheck the diff and test results, then merge the pull request. With automatic review turned on for a repository, review and fixes run first and you click Merge at the end.

What you need

macOS 13 or later on Apple Silicon or Intel. Claude Code or Codex, plus git, Python 3 and Node.js. Automatic PR review needs Claude Code.

Where your code goes

The app doesn't send your code to novum. Your agents talk to Anthropic or OpenAI as they normally do, and pushes go to your GitHub. Details

Cost

Athena Studio itself is free. AI usage is billed under your Claude or Codex plan.

Languages

English, Korean, Japanese and Chinese, for the app and for agent replies, plans, issues and commit messages.
