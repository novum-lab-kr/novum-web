How it works

A team that asks before it acts.

Athena is the team lead. It routes your request, plans the work and hands it to an agent for each repository. You step in where it matters: approving bigger changes and the final merge.

Workspaces · Agent monitorWatch steps 01 and 03 happen live, one workspace per repository.
Requests · Menu barEvery question and decision for steps 02 and 05 comes to you in one place.
Explorer · Side browserRead the diffs, plans and test pages behind step 04.
Features

Everything your agents do, on one screen.

Terminals, agents, questions and reviews used to live in different windows. Athena Studio puts them side by side.

WorkspacesA workspace for each repository with tabs and split terminals. Agents keep running when you close the app.
Agent monitorA live feed of what each agent is doing right now, tool by tool.
RequestsQuestions and decisions from agents in one list. Answer them without leaving the app.
Menu barA red dot when something needs you, plus agents, usage and progress at a glance.
ExplorerFiles, git changes and syntax-highlighted diffs next to the terminal.
Side browserPlans, the decision console and your local test pages in a drawer beside your work.

Packs

Bring your whole setup.

A pack holds one company's repositories, agents and routing rules. Keep one for each company or team you work with.

SwitchMove between packs in one click. Agents in the other pack keep working where you left them.
ShareExport a pack and your team imports it, with the same repositories, agents and rules.
Back up and restoreSave a pack with your work, including agent conversations and unfinished branches, and pick up again later.

FAQ

Questions

Can I use Athena Studio now?

Not yet. Athena Studio is in active development, and the first public build for macOS is coming soon. Get notified and we'll let you know.

Do I need to install Athena separately?

No. The app brings the Athena core with it and sets it up on first launch. You only need Claude Code or Codex.

Can my agents work while the app is closed?

Yes. Terminals and agents keep running in the background. Open the app again and you're back to the same tabs and layout.

Do agents merge code on their own?

Only if you turn it on. Automatic review and merge is off by default and is set per repository. You can keep a final click before every merge.
